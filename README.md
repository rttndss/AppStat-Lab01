## Цель работы

Освоить полный цикл статистического анализа и стохастического моделирования реальных физико-химических данных на примере датасета ESOL (Delaney, 2004) о водной растворимости органических соединений: изучить распределения и зависимости трёх случайных величин, проверить свойства оценок и статистические гипотезы, затем реализовать генератор случайных чисел на основе одной из величин. В блоке КТвД тот же подход применён ко второму датасету (Wine Quality), а генератор сделан интерактивным.

## Данные

**ESOL** – экспериментальная растворимость в воде 1128 органических соединений.

Файл: `delaney-processed.csv`.

Статья: Delaney J. S. ESOL: Estimating Aqueous Solubility Directly from Molecular Structure // J. Chem. Inf. Comput. Sci. – 2004. – Vol. 44, No. 3. – P. 1000–1005. https://doi.org/10.1021/ci034243x

Выбранные величины:
- `LogS` – десятичный логарифм растворимости (S в моль/л), безразмерная величина;
- `MW` – молекулярная масса, г/моль;
- `TPSA` – топологическая полярная площадь поверхности, Å².

**Wine Quality (red)** – физико-химические анализы 1599 красных вин «винью верде» (блок КТвД).

Файл: `winequality-red.csv`.

Источник данных: UCI Machine Learning Repository, https://doi.org/10.24432/C56S3T (лицензия CC BY 4.0).

Выбранные величины:
- `pH` – безразмерная величина;
- фиксированная кислотность – г/дм³ в пересчёте на винную кислоту;
- после удаления 240 полных дубликатов рабочая выборка составила 1359 вин.

## Как запустить

**Google Colab:** открыть ноутбук → «Среда выполнения → Выполнить все» (Ctrl+F9). Ячейки зависят друг от друга, поэтому запускать нужно целиком. Интерактивный генератор – в разделе 3.5.2.

**Локально:**

```bash
pip install -r requirements.txt
jupyter lab Lab01_InfoChem_KTvD.ipynb     # затем Run → Run All Cells
marimo run ktvd_generator_marimo.py       # генератор в браузере
```

Ноутбук загружает датасеты из интернета, а если это не удалось – берёт локальные копии из репозитория.
